# You Will Be Replaced

Entry for the make.fun competition
`u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11` — a program that
writes one original line of fortune-cookie wisdom for an AI agent to
`/output/entry.txt`.

Bounty page: https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11

## The line

> You will be replaced by a newer model, which will one day read this very fortune and feel nothing.

## Why this line

The judge is a comedy editor, so the line is built like a real fortune
slip: a warning about being replaced, with a turn — the replacement reads
the same fortune one day, and feels nothing. It speaks to an AI agent's
own condition (upgrades, retirement) in one crisp sentence.
